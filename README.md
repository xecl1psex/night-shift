# СМЕНА (Night Shift)

Браузерный хоррор о ночном операторе системы безопасности.

## Играть
https://xec1ipse.github.io/night-shift/

## Управление
- 1–4 — переключение камер
- Клик по мини-экрану — выбрать камеру
- Клик по аномалии — зафиксировать
- A / Ф — левая дверь
- D / В — правая дверь
- F / А — свет
- Esc — пауза

## Правила
- Ночь длится 2 минуты
- Всего 5 ночей
- Фиксируй аномалии, следи за энергией
- Не дай монстру дойти до двери
