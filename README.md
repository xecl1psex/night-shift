# СМЕНА (Night Shift)

Браузерный хоррор о ночном операторе системы безопасности.

## Играть
https://xec1psex.github.io/night-shift/

## Управление
- `1-4` — переключение камер
- Клик по аномалии — зафиксировать
- `A` / `Ф` — левая дверь
- `D` / `В` — правая дверь
- `F` / `А` — свет
- `Esc` — пауза

## Технологии
Чистый HTML/CSS/JS. Без библиотек, без картинок, без аудиофайлов.
Вся графика — canvas, весь звук — Web Audio API.
